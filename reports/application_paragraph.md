## Application Paragraph

My undergraduate GPA does not fully reflect my current preparation or academic direction. To demonstrate my readiness for graduate-level work, I built AthleteIQ, a local AI sport performance proof of concept on my Mac mini. The project uses wearable movement and heart-rate data to classify physical activity, display performance trends in a dashboard, and generate a coach-facing interpretation using a local language model through Ollama. Through this project, I practiced data cleaning, feature engineering, machine learning, model evaluation, dashboard development, and applied communication in a human performance context. AthleteIQ reflects my interest in using artificial intelligence to support sport science, movement analysis, and evidence-based performance assessment, which is the kind of work I hope to continue in graduate study.
